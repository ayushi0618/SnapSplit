# SnapSplit 🧾

SnapSplit is a receipt-scanning bill-splitting web application that automates expenses by parsing receipts with the Google Cloud Vision API and Gemini API, helping groups split bills seamlessly.

---

## 🚀 Built With

* **TypeScript** (98.0%) - For type-safe frontend and backend logic.
* **JavaScript** (1.1%) - For auxiliary scripts and runtime support.
* **CSS** (0.9%) - For custom styling and styling configurations.
* **React & Tailwind CSS** - For a responsive and clean user interface.
* **Supabase** - For backend database and authentication.
* **Google Cloud Vision API & Gemini API** - For intelligent receipt scanning and text extraction.
